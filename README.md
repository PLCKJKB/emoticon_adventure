# Emoticon Adventure

## Description
Emoticon Adventure is a text-based game written in Python. Explore and fight your way through a world full of Emoticon creatures and people.

## How to Launch

1. Make sure Python is installed.
2. Open the project in your code editor or terminal.
3. Run the Python file containing the game.
4. The game starts automatically through `start_adventure()`.

## Needed Imports:

1. Module `random`
2. Module `itertools`
3. Module `time`
4. Module `pick` (download with `pip install pick`)

## Controls

- **Enter:** Progress through dialogue.
- **Number keys:** Enter your answer during combat.
- **Up / Down arrows:** Navigate through available options.
- **Enter:** Confirm your selected option.
